## Changes

- Generation now requires a completed, git-ignored `profile.local.md`. Missing, template, and very short profiles stop before ingest and before an engine call.
- Dashboard generation errors retain the server's actionable message and render it through `textContent`.
- A source footer is attached after HTML validation by application code. It records source type/URL, fetch time, and a link to the local ingest record.
- `pages.json` entries retain backward-compatible `archivePath` and `fetchedAt` fields.
- The local server exposes only a flat `inputs/*.json` archive route. Path traversal, out-of-tree targets, and symlinks resolving into another allowed static class are rejected.
- Every HTTP request must use the active loopback `127.0.0.1:<port>` or `localhost:<port>` Host, limiting DNS-rebinding access to raw archives.
- The reserved provenance marker fails closed, as does generated HTML without `</body>`. Replacement uses a callback so `$&`, `$\``, and `$'` in source data remain literal.
- Provenance is inserted before the last closing `</body>`, so a literal `</body>` inside a script or template cannot capture the footer.
- When the Dashboard cannot reach the service, it again shows the exact `node engine/forge.mjs serve` recovery command.
- README first-run instructions now create `profile.local.md` (`cp profile.md profile.local.md`) rather than editing the tracked template. Later README merges dropped them; they were restored on 2026-10-31.
